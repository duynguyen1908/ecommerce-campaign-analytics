# E-commerce Campaign Dashboard

*Team project · University of Adelaide · 2026*

**Question:** Which marketing channels and campaigns actually earn their budget?

**What we did** (team of 4)
- **We** built interactive dashboards comparing channels and campaigns on cost and revenue
- **I** analysed channel, monthly and campaign performance
- **We** turned the findings into budget recommendations

**Methods**
- **KPI design:** calculated fields for average order value (AOV) and cost per order (CPO)
- **Dashboard design:** scorecards with period-over-period change, a date-range control, and a CPO target line with conditional colours
- **Performance analysis:** channel, monthly and campaign comparison across the funnel (impressions → clicks → orders → revenue)

**Result:** Found the most cost-efficient campaign (**$35.38** per order) and one running **12.1%** over its cost target.

**Tools:** Looker Studio · Google Sheets
